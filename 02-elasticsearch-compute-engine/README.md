# Episodio 02 · Elasticsearch en Compute Engine

## Objetivo

Provisionar Elasticsearch en una VM de Compute Engine, configurar almacenamiento, identidad y acceso de red seguro, y comprobar su disponibilidad.

## Resultado comprobable

Instancia accesible desde orígenes autorizados y búsqueda de prueba.

## Alcance y requisitos

No aborda embeddings ni la implementación del agente; eso corresponde a 03 y 06.

## Estado del material

Estructura educativa preparada. Los recursos ejecutables, capturas, PDFs y comandos definitivos se incorporarán solo después de ser revisados y probados.
