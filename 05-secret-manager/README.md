# Episodio 05 · Secret Manager para el agente de IA

## Objetivo

Almacenar credenciales de servicios externos en Secret Manager y dar acceso mínimo a las identidades que ejecutan las aplicaciones.

## Resultado comprobable

Uso de un secreto de prueba sin exponer su valor en código, capturas, logs o el repositorio.

## Alcance y requisitos

No se compartirán API keys, contraseñas ni conexiones reales.

## Estado del material

Estructura educativa preparada. Los recursos ejecutables, capturas, PDFs y comandos definitivos se incorporarán solo después de ser revisados y probados.
