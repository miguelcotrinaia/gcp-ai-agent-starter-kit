# Episodio 09 · API Flask, Docker y Cloud Run

## Objetivo

Integrar el agente ya existente con la API Flask, definir POST /agent con JSON, validación y manejo de errores; contenerizarlo y desplegarlo en Cloud Run con secretos y permisos seguros.

## Resultado comprobable

Solicitud autorizada al servicio desplegado y revisión de logs de Cloud Run.

## Alcance y requisitos

No incluye un curso desde cero de Flask, HTTP, Python o Docker. El código final del servicio estará en cloud-run-service/.

## Código del servicio

La carpeta [`cloud-run-service/`](../cloud-run-service/) contendrá el servicio desplegable después de revisar el código que ya tiene el autor.

## Estado del material

Estructura educativa preparada. Los recursos ejecutables, capturas, PDFs y comandos definitivos se incorporarán solo después de ser revisados y probados.
