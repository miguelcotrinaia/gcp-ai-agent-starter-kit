# Episodio 10 · Frontend Next.js sin login

## Objetivo

Configurar y desplegar la interfaz sin autenticación en Cloud Run, conectada a la API del agente. Proteger los datos de conversación mediante sesiones anónimas aisladas y controles del backend.

## Resultado comprobable

Chat funcional con sesiones independientes.

## Alcance y requisitos

Código en https://github.com/miguelcotrinaia/agentui-withoutlogin. La ausencia de login no implica una API pública sin restricciones.
