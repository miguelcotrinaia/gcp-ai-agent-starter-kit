# Episodio 11 · Frontend Next.js con Google Login

## Objetivo

Desplegar en Cloud Run la variante Next.js autenticada con Google OAuth, validando la sesión en servidor antes de invocar el agente.

## Resultado comprobable

Login, chat, cierre de sesión y autorización probados.

## Alcance y requisitos

Código en https://github.com/miguelcotrinaia/agentui-withlogin. El backend debe asociar la memoria a una identidad verificada.
