# Episodio 00 · Arquitectura del agente de IA en Google Cloud

## Objetivo

Presentar el flujo completo de la aplicación: dos alternativas de frontend Next.js en Cloud Run, API Flask del agente en Cloud Run, RAG con Elasticsearch en Compute Engine, memoria de LangGraph en Cloud SQL PostgreSQL, secretos y trazabilidad.

## Resultado comprobable

Diagrama de la arquitectura objetivo y recorrido de una consulta real.

## Alcance y requisitos

No será una introducción extensa a Python, redes o servicios de nube.

## Estado del material

Estructura educativa preparada. Los recursos ejecutables, capturas, PDFs y comandos definitivos se incorporarán solo después de ser revisados y probados.
